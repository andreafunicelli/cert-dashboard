Placement annotations

  • Header: 24px lockup, homepage link named “Cert Dashboard home”; minimum 48px hit target. Use light variant in light mode.
  • Compact navigation: mark at 24px, same homepage link name. Do not squeeze the wordmark.
  • Sign in: 48px mark above the unchanged “Sign in” heading; keep the header lockup rather than adding a second wordmark.
  • Favicon: fixed default identity, independent of custom uploads. Dark tile keeps the mark readable on browser light and dark chrome.
