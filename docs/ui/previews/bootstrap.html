No administrator exists yet

The web interface never creates the first administrator. An operator must run this command on the host:

docker compose run --rm web python -m app.cli bootstrap-admin --username admin --email admin@example.internal

The command prompts for the password twice (minimum 12 characters). Reload this page afterwards to sign in.
