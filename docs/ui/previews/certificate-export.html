The PFX contains the private key, the certificate and its stored intermediate chain. It is built in memory, encrypted with the password you choose below, and sent once; nothing is written to disk. The export is recorded in the audit log (without any password).

Keep the PFX password safe: it cannot be recovered. Passwords are never shown again, so re-enter them after any error.
