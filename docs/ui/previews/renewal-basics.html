Names

DNS names and IP addresses; the common name is always included. Use IP:, email: or URI: prefixes for other types.

Notes are shown to every administrator; do not store secrets here.

Key generation comes next

  • RSA 2048 (default): Most compatible.

Compatibility trade-off: RSA 2048 works everywhere; ECDSA is smaller and faster but not understood by every client or CA. The private key is generated here and stored encrypted; it never leaves the application.

The algorithm is chosen when you generate the CSR on the next screen; it is not saved with the draft.
