How drafts work

Save each section explicitly. Without JavaScript, unsaved changes are lost when switching tabs. Saving one section also reloads the tab and loses unsaved edits in other sections without JavaScript. With JavaScript, non-secret configuration drafts stay in this browser tab until saved. Secrets and repository URLs are never retained; save repository URL edits before switching tabs.

Worker

No unsaved draft restored. Changes are not applied until you save.

Credentials are encrypted at rest and used by the next job without a worker restart. Stored values are never shown. Secret edits and file selections are not kept as drafts: save each credential before switching tabs or saving another section. Without JavaScript, leaving this page loses unsaved input without a warning.

A database value overrides a mounted worker secret. Removing it restores the mounted value, if one exists. Credential audit history
